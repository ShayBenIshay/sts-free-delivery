# STS Free Delivery Bar

A free-shipping progress bar on the WooCommerce cart and checkout pages ("add X more for free delivery").

## How it works
There is no settings page. The plugin reads the minimum amount of the **Free shipping** method in your WooCommerce shipping zones and shows the remaining amount, updating live as the cart changes. The threshold is cached and cleared when you add, remove or toggle a shipping method.

## Requirements
WordPress 5.0+, WooCommerce 5.0+, PHP 7.4+. A Free shipping method with a minimum order amount must be configured.

## Install
Copy the folder to `wp-content/plugins/` and activate. Style it via `assets/css/free-delivery.css`.
